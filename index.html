고추건조기를 축으로 모든 도구(SolidWorks·KiCad·OpenFOAM·FPGA)를 하나씩 연결합니다. 건조기에서 익힌 PID·PWM·안전로직·통신은 드론 제어의 축소판입니다.

1

SolidWorks — 건조기 챔버 모델링

히터·팬·센서 배치 확정 → OpenFOAM 입력 형상 확보

2

OpenFOAM — 열유동 해석

확정 형상으로 팬/흡배기 위치 최적화, 정체영역 확인

3

KiCad — 제어보드 회로 설계

STM32 + SHT30 + 릴레이 + 팬 드라이버 + 안전회로

4

STM32 펌웨어 — PID 제어

온습도 PID, 오버슈트 차단, 센서 단선 감지, 데이터 로깅

5

FPGA 보안 — 로그 암호화

AES-128로 온습도 이력 암호화 → 드론 군집 통신 보안으로 확장

6

군집드론 — 통합

STM32 비행제어 + FPGA 가속 + LoRa 통신 아키텍처
